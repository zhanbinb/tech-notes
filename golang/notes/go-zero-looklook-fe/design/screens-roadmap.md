# 全站页面清单（MVP = 后端所有 API 对应的 12 页，2026-08-12 实测）

> 本清单**严格 1:1 对应后端 19 个 REST 端点**，没有虚增页面。

## 总览

| #   | 路由                    | 页面                                      | 后端 API                                     | 鉴权 | 优先 |
| --- | ----------------------- | ----------------------------------------- | -------------------------------------------- | ---- | ---- |
| 1   | `/`                     | 首页 Feed（猜你喜欢 + 好房东 + 推荐店铺） | guessList + goodBoss + homestayBussinessList | ❌   | P0   |
| 2   | `/homestay`             | 民宿列表（分页）                          | homestayList                                 | ❌   | P0   |
| 3   | `/homestay/:id`         | 民宿详情（图 / 房型 / 价格 / 评价）       | homestayDetail + commentList                 | ❌   | P0   |
| 4   | `/homestay/:id/booking` | 下单页（日期 / 人数 / 餐食 / 备注）       | createHomestayOrder                          | ✅   | P0   |
| 5   | `/landlord`             | "好房东"列表（推荐房东展示）              | homestayBussinessList + goodBoss             | ❌   | P0   |
| 6   | `/landlord/:id`         | 房东详情（房东信息 + 名下房源）           | homestayBussinessDetail + businessList       | ❌   | P0   |
| 7   | `/order`                | 我的订单（Tab 全部/待支付/有效）          | userHomestayOrderList                        | ✅   | P0   |
| 8   | `/order/:sn`            | 订单详情（价格拆解 + 入住信息 + 交易码）  | userHomestayOrderDetail                      | ✅   | P0   |
| 9   | `/pay/:sn`              | 收银台（调起微信支付 + 结果跳转）         | thirdPaymentWxPay                            | ✅   | P0   |
| 10  | `/login`                | 登录（手机号 + 密码）                     | user/login                                   | ❌   | P0   |
| 11  | `/register`             | 注册（手机号 + 密码）                     | user/register                                | ❌   | P0   |
| 12  | `/u/me`                 | 个人中心（用户信息 + 退出）               | user/detail                                  | ✅   | P0   |

## 已删除（**无后端 API 支持**，原 PRD 列了但不存在）

- ❌ `/travel` 游记 Feed
- ❌ `/travel/:id` 游记详情
- ❌ `/travel/compose` 发布游记
- ❌ `/homestay/host/new` 房东发布房源
- ❌ `/order/refund/:id` 退款申请
- ❌ `/coupon` / `/activity` / `/notifications` / `/messages` / `/admin`

## 响应式断点策略

| 设备 | 宽度         | 路由形态                                 |
| ---- | ------------ | ---------------------------------------- |
| 桌面 | >= 1024px    | 完整侧边栏 / 多列卡片 / 杂志感 hero      |
| 平板 | 768 - 1023px | 简化 2 列，无侧边栏                      |
| 移动 | < 768px      | 单列 + 底部 Tab（首页/订单/我的 三 Tab） |
