## 1. 业务背景

go-zero-looklook 是 Go 中文社区知名的"生活方式分享"微服务样板，
对标产品包含: 小红书 / Airbnb / 携程社区 / 马蜂窝。

### 1.1 核心价值主张

让用户能"**发现 → 收藏 → 体验 → 分享**"真实的旅行 / 居住场景。

### 1.2 目标用户

| 画像                            | 占比 | 关键诉求                   |
| ------------------------------- | ---- | -------------------------- |
| 旅行者（小李，25-35，城市白领） | 50%  | 发现优质游记，作为出行决策 |
| 民宿房东（王姐，30-50）         | 20%  | 发布房源、管理订单         |
| 内容创作者（小张，KOC）         | 20%  | 涨粉、变现                 |
| 商家运营（陈经理）              | 10%  | 营销投放、数据看板         |

## 2. 业务模块清单（**基于后端实际扫描**, 2026-08-12 实测修订）

> ⚠️ 本节是**事实修正**: PRD 初版我误把原 looklook 当成"小红书社区"。
> 扫描后确认这是**纯民宿短租**项目（类似 Airbnb / 木鸟），**没有内容 / 营销 / IM / ADMIN**。

| 后端服务             | 子域             | 用户故事                                         | 优先级 | 前端页面   |
| -------------------- | ---------------- | ------------------------------------------------ | ------ | ---------- |
| **usercenter :1004** | user             | 注册 / 登录（手机号）/ 微信小程序授权 / 个人详情 | P0     | 4 页       |
| **travel :1003**     | homestay         | 民宿列表 / 详情 / 猜你喜欢                       | P0     | 3 页       |
|                      | homestayBusiness | 房东列表 / 房东详情 / 房东名下房源               | P0     | 2 页       |
|                      | homestayComment  | 民宿评论列表（只读）                             | P0     | 合并到详情 |
| **order :1001**      | homestayOrder    | 创建订单 / 我的订单 / 订单详情                   | P0     | 3 页       |
| **payment :1002**    | thirdPayment     | 调起微信支付 / 支付结果                          | P0     | 1 页       |
| **mqueue**           | —                | 纯异步消息，前端不直接消费                       | —      | 0          |

### 2.1 后端没有的 API（**前端无法做**）

- 用户资料编辑（`user/update`）
- 评论发布（`comment/create`）
- 收藏 toggle（`fav/toggle`）—— `isFav` 字段返回但**只读**
- 订单取消 / 退款 —— 状态可见但无接口
- 营销券 / 通知 / IM / admin 后台

**结论**: MVP 严格 12 页，全部对应真实 API，前端零编造。

## 3. 核心用户旅程（**修订：只剩"游客下单 + 看房东"两条主线**）

### 主线 A - 游客发现 → 下单（**核心**, 9 步）

1. 打开首页 → 看到"猜你喜欢"民宿 + "好房东"推荐
2. 点击民宿卡片 → 进民宿详情 → 看图 / 房型 / 评价 / 房价
3. 点"立即预订" → 进下单页 → 选日期 / 人数 / 餐食选项
4. 提交订单 → 跳支付页 → 调起微信支付 SDK
5. 支付成功 → 跳"我的订单详情" → 看交易码 / 入住信息

### 主线 B - 看房东

1. 房东列表页 / 首页"好房东" → 进入房东详情
2. 看房东介绍 / 排名 / 其名下所有房源
3. 选一个房子回到主线 A

> **没有的旅程**：原 PRD 里"发布游记 / 涨粉 / 评论发布 / 房东发布房源"都是**无 API 支持的伪需求**，已删除。

## 4. 待你确认的关键问题

### 4.1 形态（2026-08-12 确认）

- ✅ 双形态：**H5 版 + 独立 Web 版**（同一份 Vue 代码 + 路由适配）
- ❌ 暂不需要 PWA（Stage 10 之后再评估）
- ❌ 不需要 SSR / SEO（MVP 阶段；后续如做 SEO 营销页可单独建 Nuxt 子项目）

### 4.2 视觉与品牌（2026-08-12 确认）

- ✅ **主色**：深棕褐 `#3D2E1F`（高级、克制，配色见 ADR-0002）
- ✅ **风格**：**杂志感高级版** —— 大留白 + 衬线标题 + 克制用色
- ✅ **字体**：免费方案 —— 中文 Noto Serif SC / Noto Sans SC，英文 Fraunces / Inter

### 4.3 终端（2026-08-12 确认）

- ✅ 桌面端 + 移动端响应式（**桌面优先，PC 与移动同源**）
- ✅ 断点：`sm 640 / md 768 / lg 1024 / xl 1280 / 2xl 1536`
- ❌ 小程序**暂不做**（阶段 10 之后用 uni-app / Taro 复用时再评估）

### 4.4 上线节奏（2026-08-12 确认）

- ✅ MVP = **后端全部 API 对应的页面**（详见 §2 模块清单的 P0+P1）
- ❌ **不灰度**，上线即全量

---

### 4.5 最终决策（2026-08-12，详见 ADR-0003）

- ✅ **产品定位**: 民宿短租，UI 包装为"旅行 / 体验"调性
- ✅ **支付方案**: MVP 仅做 H5（微信公众号 / 小程序 webview），用原生微信支付
- ✅ **缺失 API**: 收藏 / 评论发布 / 退款 / 资料编辑 这 4 项**暂不做**，UI 隐藏对应入口
- ✅ **后台**: MVP 不做；后续阶段用 vue-vben-admin 骨架 + 自写业务页

## 5. 非功能性需求

- 首屏 LCP < 2.5s（4G）
- Lighthouse Performance ≥ 85
- a11y 至少满足 WCAG 2.1 AA
- 兼容浏览器: Chrome/Safari/Edge 最近 2 个大版本
