# ADR-0003 产品决策记录（Q1+Q2+Q3 + Q4）

- 状态: 已接受
- 日期: 2026-08-12
- 决策人: 用户

## Q1 - 产品定位（民宿短租 + 旅行包装）

**决定**: 接受后端是纯民宿短租的事实，但 UI 文案 / 品牌调性**包装成"旅行 / 体验"**。

- ✅ 措辞: "发现 / 体验 / 在地"代替"预订 / 入住"
- ✅ 视觉: 保持杂志感高级版（ADR-0002）
- ✅ 路由命名: 用 `/homestay` 但 Hero 区文案用"在慢的地方找回自己"

## Q2 - 支付方案（**MVP 只做 H5 / 小程序 webview**）

**决定**: MVP **仅做 H5**，运行在微信公众号 / 小程序 webview 内，使用原生微信支付。

- ✅ 开发期: Vite 5173，proxy → 后端 1004/1003/1002/1001
- ✅ 部署期: nginx 反代（与后端共用）
- ✅ 收银台: 调用 `thirdPaymentWxPay` 后用 `wx.miniProgram.navigateTo` / `wx.chooseWXPay` 调起原生支付
- ❌ 独立 Web 端**未做**收银台，对未识别环境的用户显示"请在微信中打开"
- 后台补 H5 支付预留: 接口层封装 `usePaymentLauncher()`，未来加上扫码支付 / 跳转 URL schema 就可用

## Q3 - 缺失 API 的应对

**决定**: MVP **不做**收藏 toggle / 评论发布 / 订单取消 / 资料编辑，UI 上隐藏对应入口。

- ✅ isFav 字段展示但不响应点击
- ✅ 评论列表只读，无输入框
- ✅ 订单状态"已取消"按钮**不下发**
- ✅ 个人中心不放"编辑资料"按钮
- 📌 后续: 后端补全这 4 个 API 后，前端只补 UI 按钮 + 调用，不改架构

## Q4 - 管理后台方案

**决定**:

- MVP / 阶段 6-10 **不做后台**，screens-roadmap 中 P3 项
- 阶段 11+ 起做时: fork **`vue-vben-admin`**（Vue3+Vite+TS+Element Plus，栈 100% 一致）的 layout/路由/RBAC/字典 骨架，业务页（民宿审核 / 订单管理）自写
- 暂不动后端，待后续单独讨论 admin role 鉴权
